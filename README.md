# Αγγλική γραμματική

Στατική ιστοσελίδα με ξεχωριστό περιεχόμενο UTF-8. Χωρίς βιβλιοθήκες, npm, API ή βάση δεδομένων.

## Ανέβασμα στο develop

1. Επίλεξε το branch `develop` στο GitHub.
2. Ανέβασε ΟΛΑ τα περιεχόμενα αυτού του φακέλου στην αρχική θέση του αποθετηρίου, διατηρώντας τους φακέλους `assets`, `content`, `offline`. Μην ανεβάσεις τον εξωτερικό φάκελο ή το ZIP.
3. Τα index.html, exercises.html, rules.html και English-Grammar-Quiz.html αντικαθιστούν τις παλιές εκδόσεις. Το PDF διατηρείται.
4. Άφησε τα GitHub Pages στο main / (root). Η παραγωγική έκδοση αλλάζει όταν συγχωνεύσεις το develop στο main μέσω Pull Request.
5. Αν το GitHub δεν επιτρέπει αντικατάσταση υπάρχοντος αρχείου από Upload files, άνοιξέ το και χρησιμοποίησε Edit, ή κάνε τις αντικαταστάσεις μέσω τοπικού Git. Μην δημιουργήσεις διπλά αρχεία.

## Αλλαγή περιεχομένου

- content/quiz.json: question, options (4 επιλογές), correctIndex (0=A, 1=B, 2=C, 3=D), hint, explanation.
- content/exercises.json: question, answer.
- content/rules.json: ενότητες με title και blocks. Κείμενο: {"type":"text","text":"..."}. Πίνακας: {"type":"table","headers":[...],"rows":[[...],...]}. Κάθε σειρά έχει τόσα κελιά όσα οι τίτλοι.
- assets/style.css: εμφάνιση.
- assets/quiz.js: λειτουργία κουίζ.
- assets/content.js: εμφάνιση ασκήσεων και κανόνων.

Το JSON απαιτεί διπλά εισαγωγικά και δεν επιτρέπει σχόλια ή τελικό κόμμα μετά το τελευταίο στοιχείο. Για εισαγωγικά μέσα σε κείμενο γράψε \". Κράτησε κωδικοποίηση UTF-8.

Οι σελίδες της ιστοσελίδας διαβάζουν απευθείας τα JSON. Μπορείς να προσθέσεις ή να αφαιρέσεις ερωτήσεις· ο αριθμός και το σκορ προσαρμόζονται.

## Έλεγχος στον υπολογιστή

Με Python 3, από αυτόν τον φάκελο:

    python -m http.server 8000 --bind 127.0.0.1

Άνοιξε http://localhost:8000. Σταμάτησε με Ctrl+C. Τα κανονικά HTML χρειάζονται server για να διαβάσουν τα JSON.

## Χρήση με διπλό κλικ χωρίς server

Άνοιξε offline/index.html. Οι τρεις σελίδες και το PDF λειτουργούν χωρίς διαδίκτυο.
Μετά από αλλαγές εκτέλεσε:

    python build.py

Ελέγχει τα JSON και ενημερώνει τον φάκελο offline και το ανεξάρτητο English-Grammar-Quiz.html. Ανέβασε και αυτά τα ενημερωμένα αρχεία για να συμφωνούν οι εκδόσεις λήψης με το περιεχόμενο.

## PDF

Το PDF είναι η υπάρχουσα έκδοση των 60 ασκήσεων και κανόνων. Το build.py ΔΕΝ το αναδημιουργεί. Αν αλλάξεις την ύλη, ενημέρωσε και το PDF ξεχωριστά.

## Σκορ

Διατηρείται στη μνήμη της ανοιχτής σελίδας. Δεν αποθηκεύεται σε server. Οι απαντήσεις είναι ορατές στον κώδικα: εκπαιδευτικό εργαλείο, όχι πλατφόρμα ασφαλών εξετάσεων.

## Παλιά source και build.py

Αν είχες ανεβάσει τον προηγούμενο φάκελο source ή make.py, μπορείς να τα διαγράψεις στο develop: η νέα πηγή είναι ο φάκελος content. Αντικατάστησε το παλιό build.py με αυτό της νέας έκδοσης.
